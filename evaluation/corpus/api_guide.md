# API 与后端说明（Benchmark v2）

本项目后端框架为 FastAPI。

后端默认监听端口为 8000。

用户上传文档后，后端会依次完成文档读取、文本切分、向量生成和 FAISS 索引更新。

RAG 问答接口可以携带 session_id，用于关联多轮对话上下文。

RAG 返回结果除了 answer 外，还可以包含 sources，用于展示回答所依据的知识来源。

普通聊天模式不强制执行知识库检索；RAG 问答模式会先检索知识库，再基于检索上下文生成回答。

清空对话记忆只会删除会话历史，不会删除已经构建的知识库索引。

项目根目录可以通过 run.py 启动 Web 服务。

服务启动后，本机浏览器可以访问 http://127.0.0.1:8000。

真实运行配置主要存放在 frontend/local_rag/.env 文件中。
