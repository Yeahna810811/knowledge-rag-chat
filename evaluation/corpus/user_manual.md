# 用户使用手册（Benchmark v2）

当前系统明确支持 TXT、Markdown、PDF、DOCX 和 CSV 五种文档格式。

现有文档没有声明支持 XLSX。

用户从 Web 页面上传文档后，系统会自动完成解析、文本切分、向量化和索引更新。

同一个知识库可以包含多个文档，检索会在所有已建立索引的文本块中进行。

知识问答模式适合公司制度、项目文档、产品说明和个人资料库等需要基于指定文档回答的场景。

连续多轮请求如果使用相同的 session_id，系统可以保留同一会话上下文。

清空对话记忆后，知识库索引仍然保留。

执行“清空知识&记忆”会同时清理知识库状态和相关会话记忆。

当前版本未实现语音输入和 OCR 自动识别。

Hugging Face unauthenticated warning 只表示当前没有使用 HF_TOKEN；如果公开模型仍能正常下载和加载，该警告不等于程序运行失败。
