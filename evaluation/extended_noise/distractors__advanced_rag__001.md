题，它只看排名不看分数，
公式里的常数 k 控制头部排名的权重，通常取 60。

## 结果重排

召回阶段为了速度，query 和 doc 是分别独立编码的，两者没有交互。
重排阶段把 top-N 候选拿出来，用交叉编码器把 query 和 doc 拼在一起
过一遍模型，精度更高但慢得多。所以重排只对少量候选做，
通常是「召回 50 到 100，重排后取 5」。

需要注意重排模型的语言必须与语料匹配。用只在英文上训练的重排模型
处理中文文档，效果可能还不如不重排。

## 表格与图片

技术文档里的关键信息经常在表格里，而表格被切分后行与列的对应关系会丢失。
常见处理是把表格整体转成 Markdown 文本或者自然语言描述后再入库，
并在元数据里标记它来自表格，检索时可以适当加权。

图片的处理更麻烦：需要先 OCR 或者用多模态模型生成描述，
再把描述文本入库。直接把图片丢给嵌入模型，得到的向量语义不可控。
