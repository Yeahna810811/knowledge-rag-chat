# 全文检索与倒排索引原理（通用技术资料）

说明：本文档是通用技术资料，用作评测干扰语料。

## 倒排索引

正向索引是「文档 -> 词列表」，倒排索引是「词 -> 文档列表」。
检索时先把查询切成词，再对每个词取出对应的文档列表做归并，
避免了全表扫描，这是搜索引擎能做到毫秒级响应的基础。

倒排表里除了文档编号，通常还要存词频和位置信息。
位置信息用于短语查询——「机器学习」要求两个字相邻且顺序正确，
只有词频无法判断这一点。

## 中文分词

中文没有空格，必须先分词才能建倒排索引。主流分词器基于词典 +
统计模型，需要处理两类歧义：交集型（「研究生命起源」）
和组合型（「中国人民银行」）。

分词粒度直接影响效果。切得太细，「机器学习」被切成两个单字，
短语查询失效；切得太粗，用户查询「学习」命中不了「机器学习」。
实践中常用的办法是混合粒度建索引：既索引粗粒度词也索引细粒度词，
查询时按最长匹配优先。

另一种完全绕开分词的方案是 N-gram：把文本切成所有长度为 N 的连续子串。
对中文取 N=2 效果不错，代价是索引膨胀且会引入噪声匹配。
